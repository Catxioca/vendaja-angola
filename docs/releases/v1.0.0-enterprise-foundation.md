## 1. Visão Geral da Release
A release **VendaJá Angola Enterprise Foundation (`v1.0.0-enterprise-foundation`)** marca a consolidação oficial da transformação do ERP num ecossistema de software empresarial robusto, seguro, modular e omnichannel de nível Tier 1.

O sistema integra a estabilização de regras fiscais homologadas da Administração Geral Tributária (AGT), governação de segurança corporativa com RBAC e auditoria forense, fluxos de workflow, CRM 360º, APIs públicas com webhooks, contabilidade PGCA e tesouraria, Business Intelligence preditivo, arquitetura Cloud SaaS multi-tenant, licenciamento modular em dois níveis com proteção DRM offline, e portais self-service para clientes, fornecedores e colaboradores (RH LGT 22 dias), complementados por uma aplicação móvel corporativa com CRM georreferenciado e tolerância offline com garantias de idempotência.

---

## 2. Destaques da Versão

### 2.1 Licenciamento Modular em Dois Níveis
- Separação entre a autorização base do produto e a autorização de módulos individuais.
- Instalações reais iniciam com módulos operacionais bloqueados até que licenças válidas assinadas por RSA-2048 sejam aplicadas.
- Preservação definitiva de licenças e dados reais durante atualizações de versão sem dados simulados.

### 2.2 Portais Self-Service e Experiência Digital (Fase 9)
- **Portal do Cliente**: Extrato com saldo corrido contínuo e liquidação via referências Multicaixa GPO (Entidade `00142`) e transferências BAI/BFA.
- **Portal do Fornecedor**: Acompanhamento de Ordens de Compra e submissão eletrónica de faturas comerciais para conferência da contabilidade.
- **Portal do Colaborador (RH)**: Gestão de férias segundo os 22 dias úteis da Lei Geral do Trabalho de Angola (LGT Lei n.º 12/23), pedidos de ausência via workflow e recibos com retenção discriminada de IRT e dedução de 3% para o INSS.
- **Mobile ERP (Android & iOS)**: Cockpit de BI para Diretores, aprovações corporativas em 1-toque, registo de visitas comerciais com GPS e assinatura digital, e sincronização offline com desduplicação por UUID v4.

### 2.3 Correções Críticas de POS e Integridade Fiscal
- Paridade matemática total entre Venda, Fatura, Impressão e Caixa.
- Eliminação de qualquer recálculo de valores ou troco na emissão de documentos.
- Dashboard funcional em modo offline alimentado por dados reais da base local.

## 4. Instruções de Atualização e Deployment
1. **Configuração de Ambiente**:
   - Clonar o repositório a partir de `https://github.com/Catxioca/vendaja-angola.git`.
   - Copiar `.env.example` para `.env` e configurar as credenciais do banco de dados PostgreSQL.
2. **Dependências e Migrações**:
   ```bash
   npm install
   npm --prefix apps/backend run prisma:migrate:deploy
   ```
3. **Compilação e Execução**:
   ```bash
   npm run build
   npm --prefix apps/backend start
   ```
4. **Licenciamento**:
   - No primeiro arranque, utilize o painel de administração para carregar a licença do produto e as licenças modulares contratadas (`*.key`).
